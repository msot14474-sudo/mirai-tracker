# Mirai Tracker Future Enhancement Proposals

Prepared: 21 October 2026

Four proposed enhancements for future development across HI-Tech, Jaggannath and Rathinam campuses. Each would respect the existing campus, batch, subject and role permissions.

1. **Faculty lecture logging through WhatsApp:** Extend the existing integration so faculty can send lecture details, topics covered and pending work through WhatsApp. AI would match the message to the assigned class, ask for any missing details and show a preview for confirmation before updating the lecture record and subject progress.

2. **Student lecture reviews and satisfaction:** Allow students to rate each lecture and share unclear topics or comments. The assigned faculty member would receive a feedback summary and concerns requiring follow-up. Unresolved concerns would escalate to the campus manager and then the administrator after a configurable period. Students would see their own submissions, and routine faculty summaries would keep student identities private.

3. **Topic-linked learning resources:** Allow faculty to attach notes, reference links and practice material to lesson-plan topics. Students would find published resources alongside their covered topics, upcoming lectures and exam syllabus. Materials would stay linked to the topic when class dates change.

4. **Short quizzes and revision suggestions:** Let faculty create short topic-based quizzes, with optional AI-generated questions reviewed by the teacher before publishing. Students would receive answer explanations, and faculty would see which topics need revision. Quiz results would measure understanding separately from recorded teaching completion.
